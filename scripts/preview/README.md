# Local Preview Styles

- `preview.css` contains the HANCORE preview shell and responsive theme overrides.
- `github-markdown.min.css` is generated by [github-markdown-css](https://github.com/sindresorhus/github-markdown-css). Its MIT notice is preserved in `LICENSE-github-markdown-css`.

Run `python scripts/render_previews.py` from the repository root, then open `preview.html`. Add `?theme=dark` or `?theme=light` to test a specific color mode.
